# Vidu 视频生成 · 概述

> PinduCloud 提供本页所列接口。请求使用 PinduCloud API Key；模型开通情况以当前账号的可用模型为准，参数按本页对应型号的协议组织。

---

## 能力简介

Vidu 视频生成支持以下任务类型，分别通过独立的接口提交：

| 任务类型 | 接口路径 | 说明 |
|:---|:---|:---|
| 文生视频（T2V） | `POST /vidu/ent/v2/text2video` | 根据文本提示词生成视频 |
| 图生视频（I2V） | `POST /vidu/ent/v2/img2video` | 以首帧图片驱动生成视频 |
| 参考生视频 | `POST /vidu/ent/v2/reference2video` | 以参考图片/视频的主体一致性生成视频，支持主体库 |
| 首尾帧 | `POST /vidu/ent/v2/start-end2video` | 指定首帧和尾帧图片生成过渡视频 |
| 智能多帧 | `POST /vidu/ent/v2/multiframe` | 多个关键帧图片生成长视频 |
| 场景特效模板 | `POST /vidu/ent/v2/template` | 基于预设场景模板生成特效视频 |
| 模板成片 | `POST /vidu/ent/v2/template-story` | 基于故事模板一键生成成片 |

视频生成为**异步任务**：提交后立即返回 `task_id`，需通过[查询任务接口](/docs/video/vidu/query)轮询任务状态；任务成功后响应中包含 `creations[].url`（视频下载地址，有效期以实际返回地址为准），请及时下载或转存。

## 标准调用流程

```text
创建任务 (POST /vidu/ent/v2/{endpoint})
        │  返回 task_id + state: "created"
        ▼
查询状态 (GET /vidu/ent/v2/tasks?task_ids={task_id})   ← 轮询直至 success 或 failed
        │  返回 creations[].url（请在链接有效期内下载）
        ▼
下载视频文件
```

| 图生视频 | `POST` | `https://video.pinducloud.com.cn/vidu/ent/v2/img2video` |

> **路径规则**：在平台域名后追加渠道前缀 `/vidu`，再拼接 Vidu 官方原始路径即可。
> 例如官方 `https://api.vidu.cn/ent/v2/text2video` → 平台 `https://video.pinducloud.com.cn/vidu/ent/v2/text2video`。

## 鉴权

所有请求均通过 HTTP `Authorization` 头携带 Bearer Token 进行鉴权：

```text
Authorization: Bearer sk-your-pinducloud-token
```

`sk-your-pinducloud-token` 为您在平台控制台创建的接口密钥。

> **注意**：Vidu 官方接口使用 `Token` 前缀鉴权，但本平台统一使用 `Bearer` 前缀。请勿使用 `Token` 前缀，否则会返回「无效的令牌」错误。

## 请求头

| 头部 | 必填 | 说明 |
|:---|:---:|:---|
| `Authorization` | 是 | `Bearer sk-your-pinducloud-token` |
| `Content-Type` | 条件必填 | POST 请求使用 `application/json`；GET 查询可省略 |

## 任务状态值

| 状态 | 含义 |
|:---|:---|
| `created` | 创建成功 |
| `queueing` | 排队中 |
| `processing` | 处理中 |
| `success` | 生成成功 |
| `failed` | 生成失败 |

## 回调通知

创建任务可传入 `callback_url`。该参数发送给任务服务；回调是否可用、通知格式和重试策略以任务服务实际行为为准，最终状态请通过本站查询接口确认。

回调中的任务标识可能与本站公开任务 ID 不同。请保存创建响应中的 `task_id`，使用它查询本站任务。

## PinduCloud 调用说明

- 服务地址为 `https://video.pinducloud.com.cn`，鉴权使用本站创建的 API Key。
- 视频任务提交成功表示任务已受理；请保存响应返回的任务 ID，并使用同一用户的 API Key 查询最终状态。
- 本站查询仅返回当前用户可访问的任务；任务数据中的可选字段取决于任务服务返回的结果。
- 原生响应中的 `credits`、`final_unit_deduction` 等积分字段不代表本站最终扣费，实际费用以站内使用日志为准。

- `viduq3-pro` 等型号是否支持参考生视频取决于对应服务的模型能力；使用前请确认该型号已开通此能力，或选择支持参考生视频的 `viduq3-turbo`。

场景模板和模板成片接口省略 `model` 时默认使用 `viduq2`；账号没有该型号权限时，应显式传入已开通的 Vidu 型号。
