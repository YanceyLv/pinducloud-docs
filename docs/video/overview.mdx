# 视频生成接口

PinduCloud 提供豆包 Seedance、MiniMax-H3、Vidu Q3、Kling V3、Kling V3 Omni、
Wan3.0 和 Wan3.0 Prime 视频接口。不同模型的请求字段、任务状态和结果获取方式不同，
请按对应页面的接口说明调用。所有示例均使用 PinduCloud API Key。

标记为“本站拒绝”的参数会在任务提交前被 PinduCloud 拒绝。未列出的参数不属于本站
公开接口约定，不能据此认定受支持。

## 服务地址与鉴权

视频接口的公共地址为：

~~~text
https://video.pinducloud.com.cn
~~~

所有请求使用 PinduCloud API Key：

~~~bash
export BASE_URL="https://video.pinducloud.com.cn"
export API_KEY="sk-your-pinducloud-token"
~~~

请求头：

~~~http
Authorization: Bearer <PINDUCLOUD_API_KEY>
Content-Type: application/json
~~~

## 统一任务流程

1. 调用创建接口并保存响应中的 `id` 或 `task_id`。
2. 使用创建响应中的公开任务 ID 调用对应查询接口。
3. 按各接口规定的成功状态读取视频 URL 或文本结果。
4. 在链接有效期内下载或转存视频；签名 URL 不作为永久存储地址。

任务状态字段和取值因接口而异，见对应模型页面。创建接口返回成功只表示任务已受理；
请使用对应查询接口确认任务完成，再获取视频结果。列表查询有分页和筛选条件，未出现在当前列表中不代表任务不存在。
查询不到任务时，先核对创建响应中的公开 ID、接口类型及 API Key 所属用户，不要重复创建任务。

## 示例与调用说明

示例中的 API Key、任务 ID、主体 ID、素材地址和响应内容均为示意，调用时须替换为真实值。
`example.com` 不是可直接使用的测试素材地址。curl 示例采用 Bash 语法；Windows 调用时应使用
`curl.exe`，并按所用终端调整引号和换行方式。响应代码块中的注释用于解释字段，不属于实际 JSON 响应。

模型在账号中可见，不代表该型号支持栏目中的全部功能。请按每个接口的型号、规格和素材要求组织请求。
创建和查询的响应结构因接口而异；原生可选字段可能缺失，不应按示例要求所有字段始终存在。

## 费用与失败处理

视频生成提交成功后会预扣额度，任务完成后按本站配置的模型价格及可用用量信息结算，可能产生退款或补扣。
视频任务失败后退还该任务预扣额度，具体金额和差额处理以使用日志为准。原生响应中的 `usage`、`credits`
或 `final_unit_deduction` 是用量或任务服务信息，不能直接当作本站扣费金额。

HTTP 请求成功不代表视频生成成功，仍需检查任务的最终状态。创建请求超时或返回不明确的错误时，
先检查已有任务和业务关联记录；避免直接重试创建请求而产生重复任务。查询请求可适当重试，建议间隔 5–15 秒。

## 接口类型

| 接口 | 请求形式 | 任务查询方式 |
| --- | --- | --- |
| Seedance | 豆包原生任务接口；素材引用使用多模态 `content` | Seedance 任务查询、列表和删除路由 |
| MiniMax-H3 | Hailuo 视频生成、视频再生成和 Context-IR 接口 | H3 单任务、列表和删除路由 |
| Vidu | `/vidu/ent/v2` 路由；各任务类型使用独立创建接口 | `/vidu/ent/v2/tasks` 列表及 `/v1/videos/{task_id}` 单任务查询 |
| Kling 新版 | 操作类型和模型名位于请求路径 | `/kling/tasks` 查询列表，`/v1/videos/{task_id}` 查询单任务 |
| Kling 原版 | 各视频、音频和素材管理能力使用独立路径；模型名放在请求体中 | 任务型接口各自提供单任务查询和列表路径 |
| Wan | DashScope 风格的 `model`、`input` 和 `parameters` 请求体 | `/ali/api/v1/tasks/{task_id}` 查询任务 |
