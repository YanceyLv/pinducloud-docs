# Wan 视频生成接口

本文汇总 Wan 文生视频、图生视频、参考生视频、视频编辑、首尾帧、动作迁移、数字人和 VACE 接口。
支持的模型以当前 API Key 的 `GET /v1/models` 返回结果为准。

## 服务地址与鉴权

~~~bash
export BASE_URL="https://video.pinducloud.com.cn"
export API_KEY="sk-your-api-key"
export TASK_ID="task-id-from-creation-response"
~~~

请求头使用 `Authorization: Bearer $API_KEY` 和 `Content-Type: application/json`。

## 接口总览

| 能力 | 方法与路径 | 主要模型 |
| --- | --- | --- |
| 文生视频、图生视频、参考生视频、视频编辑、VACE | `POST /ali/api/v1/services/aigc/video-generation/video-synthesis` | Wan 3.0、2.7、2.6、2.5、2.2、Wanx 2.1 |
| 首尾帧、动作迁移、数字人 | `POST /ali/api/v1/services/aigc/image2video/video-synthesis` | Kf2v、Animate、S2V 系列 |
| 人脸检测 | `POST /ali/api/v1/services/aigc/image2video/face-detect` | `wan2.2-s2v-detect` |
| 查询任务 | `GET /ali/api/v1/tasks/{task_id}` | 所有异步任务 |
| 通用查询与视频下载 | `GET /v1/videos/{task_id}`、`GET /v1/videos/{task_id}/content` | 所有视频任务 |

视频任务为异步任务。创建成功会返回 `output.task_id`；人脸检测是同步接口。

| `wanx2.1-vace-plus` | 多模态视频编辑 | `input.function` 及对应素材 |

## 两种请求协议

Wan 2.7 接口使用 `input.media` 描述素材，输出规格使用 `parameters.resolution` 和可选的 `parameters.ratio`。
Wan 2.6 及更早型号通常使用 `input.img_url`、`input.reference_urls` 等字段，并以 `parameters.size` 指定像素尺寸。
Wan 3.0 的 `resolution`、`ratio` 和媒体组合按下方示例使用。

## 请求字段总览

以下字段按模型和任务类型使用；不要把不同协议的分辨率字段混用。

| 字段 | 适用范围 | 说明 |
| --- | --- | --- |
| `model` | 全部接口 | 必填的模型名；使用当前 API Key 已开通的模型 |
| `input.prompt` | 文生、图生、参考生、编辑、VACE | 文本提示词；部分模型允许省略或有不同长度限制 |
| `input.negative_prompt` | 支持该参数的生成模型 | 描述不希望出现的内容 |
| `input.media` | Wan 2.7、Wan 3.0 | 以 `{type, url}` 传素材；合法类型和组合随型号而异，详见各型号的媒体输入说明 |
| `input.img_url` | Wan 2.6 及部分旧型号图生 | 输入图片地址 |
| `input.reference_urls` | Wan 2.6 参考生 | 图片和视频 URL 数组 |
| `input.first_frame_url`、`input.last_frame_url` | 首尾帧模型 | 常规 KF2V 任务需要首帧和尾帧；`wanx2.1-kf2v-plus` 模板模式仅需首帧 |
| `input.image_url`、`input.video_url` | 动作迁移、数字人、视频编辑 | 人物图片和/或作为输入的视频地址 |
| `input.audio_url` | 支持音频输入的模型 | 公网可访问的 WAV 或 MP3 音频地址 |
| `input.function` | `wanx2.1-vace-plus` | 选择 VACE 编辑类型 |
| `parameters.resolution` | Wan 2.7、Wan 3.0 | 分辨率档位，如 `720P`、`1080P`；Wan 3.0 还支持 `480P` |
| `parameters.ratio` | Wan 2.7、Wan 3.0 | 宽高比；有首帧输入时可能按首帧比例输出 |
| `parameters.size` | Wan 2.6 及更早的多数模型 | 具体像素尺寸，如 `1280*720` |
| `parameters.duration` | 可自定义时长的模型 | 整数秒；部分旧型号固定时长，不应传入 |
| `parameters.prompt_extend`、`parameters.watermark`、`parameters.seed` | 支持该参数的生成模型 | 提示词改写、水印和随机种子 |
| `parameters.shot_type` | Wan 2.6 部分模型 | `single` 或 `multi`；Wan 2.7 使用提示词描述镜头，不使用此字段 |
| `parameters.audio` | 部分 Wan 2.6 Flash 型号 | 是否生成音频；其他型号可能忽略或拒绝 |

### Wan 3.0 文生视频

~~~bash
curl --request POST "$BASE_URL/ali/api/v1/services/aigc/video-generation/video-synthesis" \
  --header "Authorization: Bearer $API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "wan3.0-video",
    "input": {
      "prompt": "A red paper kite floats above a quiet green field."
    },
    "parameters": {
      "resolution": "480P",
      "ratio": "4:3",
      "duration": 2
    }
  }'
~~~

### Wan 3.0 素材输入

Wan 3.0 的 `input.media` 项使用 `{type, url}` 结构。插件接受 `first_frame`、`last_frame`、`reference_image`、
`reference_video`、`reference_audio`、`file` 和 `link` 类型，并按类型限制数量：首帧/尾帧各最多 1 项，参考图最多 10 项，
参考视频/音频各最多 5 项，`file` 和 `link` 各最多 1 项。`last_frame` 不能单独出现；首尾帧不能与参考素材混用，
`file` 与 `link` 不能同时传。具体媒体格式和组合仍需满足所选模型的上游要求。

~~~bash
curl --request POST "$BASE_URL/ali/api/v1/services/aigc/video-generation/video-synthesis" \
  --header "Authorization: Bearer $API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "wan3.0-video",
    "input": {
      "prompt": "Continue the motion in the reference clip.",
      "media": [
        {"type": "reference_video", "url": "https://example.com/reference.mp4"}
      ]
    },
    "parameters": {"resolution": "720P", "duration": 5}
  }'
~~~

## Wan 2.7 媒体输入

Wan 2.7 图生视频通过 `input.media` 指定素材。合法组合包括 `first_frame`、`first_frame + last_frame`、
`first_frame + driving_audio`、`first_frame + last_frame + driving_audio`，以及 `first_clip`（可再加 `last_frame`）。
每种媒体类型在数组中最多出现一次。

~~~bash
curl --request POST "$BASE_URL/ali/api/v1/services/aigc/video-generation/video-synthesis" \
  --header "Authorization: Bearer $API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "wan2.7-i2v",
    "input": {
      "prompt": "The flowers sway gently as the camera moves forward.",
      "media": [
        {"type": "first_frame", "url": "https://example.com/first.jpg"},
        {"type": "last_frame", "url": "https://example.com/last.jpg"}
      ]
    },
    "parameters": {
      "resolution": "720P",
      "duration": 5
    }
  }'
~~~

Wan 2.7 参考生视频使用 `wan2.7-r2v`，`input.media` 中的类型为 `reference_image`、`reference_video` 或 `first_frame`；
提示词可以按素材顺序用“图1”“视频1”或 `Image 1`、`Video 1` 引用素材。参考图片和参考视频最多合计 5 个。

Wan 2.7 文生视频可使用 `input.audio_url` 提供音频；图生视频在 `input.media` 中使用 `type: "driving_audio"`。
音频需为 WAV/MP3，2–30 秒且不超过 15 MB。参考生视频通过 `input.media[].reference_voice` 指定参考角色音色。

## Wan 2.6 及更早版本

旧版协议通常使用 `input.prompt`、`input.img_url`、`input.reference_urls` 或 `input.template`。
`parameters.size` 必须是具体像素尺寸，例如 `1280*720`；不可传 `720P` 或宽高比字符串。

~~~bash
curl --request POST "$BASE_URL/ali/api/v1/services/aigc/video-generation/video-synthesis" \
  --header "Authorization: Bearer $API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "wan2.6-t2v",
    "input": {
      "prompt": "Cherry blossoms drift through a quiet courtyard in spring."
    },
    "parameters": {
      "size": "1280*720",
      "duration": 5,
      "shot_type": "single"
    }
  }'
~~~

`wan2.6-r2v` 和 `wan2.6-r2v-flash` 使用 `input.reference_urls`，图像和视频 URL 可混合传入，最多合计 5 个，
提示词可用 `character1`、`character2` 等名称引用。旧版 `wan2.6-i2v` 使用 `input.img_url`；部分图生模型支持 `audio_url`。

## 视频编辑与特效

### Wan 2.7 视频编辑

`wan2.7-videoedit` 使用视频生成路径，`input.media` 必须包含一个 `video`，可附带最多 4 张 `reference_image`；
`input.prompt` 描述编辑指令。`parameters.audio_setting` 可设为 `auto` 或 `origin`。

### VACE

`wanx2.1-vace-plus` 使用视频生成路径。所有请求均需 `input.function` 和 `input.prompt`；通过 `function`
选择以下五种操作。插件会将 `parameters.duration` 固定为 5 秒；涉及输入视频的操作仍受上游输入和输出时长规则约束，最长为 5 秒。

| `input.function` | 必需输入 | 可选输入/参数 |
| --- | --- | --- |
| `image_reference` | `input.ref_images_url`，1–3 张图 | `parameters.obj_or_bg` 与图片一一对应，值为 `obj` 或 `bg`（最多一个背景）；`parameters.size` |
| `video_repainting` | `input.video_url`、`parameters.control_condition` | 最多 1 张 `input.ref_images_url`；`parameters.strength`，范围 0–1 |
| `video_edit` | `input.video_url`、`input.mask_image_url` 或 `input.mask_video_url`（必须且只能传一种掩码） | 最多 1 张参考图；`input.mask_frame_id` 仅用于图片掩码；`parameters.control_condition`、`mask_type`、`expand_ratio`、`expand_mode`、`size` |
| `video_extension` | 至少提供首/尾帧图或首/尾片段之一 | `input.first_frame_url`、`last_frame_url`、`first_clip_url`、`last_clip_url`、`video_url`；传入 `video_url` 时 `parameters.control_condition` 必须为 `posebodyface` 或 `depth` |
| `video_outpainting` | `input.video_url` | `parameters.top_scale`、`bottom_scale`、`left_scale`、`right_scale`，各为 1.0–2.0 |

`video_repainting` 的 `control_condition` 可用 `posebodyface`、`posebody`、`depth`、`scribble`；`video_edit`
和带 `video_url` 的 `video_extension` 仅接受 `posebodyface` 或 `depth`。`mask_type` 可用 `tracking` 或 `fixed`，
默认 `tracking`；`expand_ratio` 为 0–1，默认 `0.05`；`expand_mode` 可用 `hull`、`bbox` 或 `original`，默认 `hull`。
掩码图片必须与输入视频分辨率一致，白色表示编辑区、黑色表示保留区；掩码视频需与输入视频的格式、帧率、分辨率和长度相同。
输入图片支持 JPG、JPEG、PNG、BMP、TIFF、WEBP，宽高 360–2000 像素且不超过 10 MB；输入视频为 MP4、帧率至少 16 FPS、
不超过 50 MB 且时长不超过 5 秒。首尾片段各不超过 3 秒，同时使用时合计不超过 3 秒。视频扩展的最终时长总计为 5 秒，
包含输入片段，不是在原视频外再增加 5 秒。

VACE 提示词最长 800 字符。通用参数还包括 `parameters.duration`（固定为 5）、`prompt_extend`（默认 true）、
`seed`（0 至 2147483647）和 `watermark`（默认 false）。

### 首尾帧、动作迁移与数字人

| 模型/能力 | 创建路径 | 输入字段 |
| --- | --- | --- |
| `wan2.2-kf2v-flash`、`wanx2.1-kf2v-plus` | `/ali/api/v1/services/aigc/image2video/video-synthesis` | 常规任务需 `input.first_frame_url` 和 `input.last_frame_url`；`wanx2.1-kf2v-plus` 模板模式仅需首帧 |
| `wan2.2-animate-move`、`wan2.2-animate-mix` | 同上 | 图片和动作视频；分别用于动作迁移和视频换人 |
| `wan2.2-s2v` | 同上 | `input.image_url` 与 `input.audio_url` |
| `wan2.2-s2v-detect` | `/ali/api/v1/services/aigc/image2video/face-detect` | `input.image_url`，同步返回检测结果 |

`wanx2.1-kf2v-plus` 还支持 `input.template` 特效模板；使用模板时只需首帧，提示词和尾帧会被忽略。

### 动作迁移与视频换人

`wan2.2-animate-move` 将参考视频中的动作迁移到输入人物图片；`wan2.2-animate-mix` 将视频中的人物替换为图片人物。
两者都使用 `/ali/api/v1/services/aigc/image2video/video-synthesis`，请求字段如下：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `input.image_url` | 是 | 人物图片 URL |
| `input.video_url` | 是 | 动作参考视频 URL |
| `parameters.mode` | 是 | `wan-std` 或 `wan-pro` |
| `parameters.check_image` | 否 | 是否在处理前检查输入图片，默认 `true` |
| `input.watermark` | 否 | 是否添加生成标记 |

图片支持 JPG、JPEG、PNG、BMP、WEBP，宽高均为 200–4096 像素，宽高比为 `1:3` 到 `3:1`，文件不超过 5 MB。
视频支持 MP4、AVI、MOV，宽高均为 200–2048 像素，宽高比为 `1:3` 到 `3:1`，时长 2–30 秒，文件不超过 200 MB。

~~~bash
curl --request POST "$BASE_URL/ali/api/v1/services/aigc/image2video/video-synthesis" \
  --header "Authorization: Bearer $API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "wan2.2-animate-move",
    "input": {
      "image_url": "https://example.com/person.jpg",
      "video_url": "https://example.com/motion.mp4"
    },
    "parameters": {
      "mode": "wan-std"
    }
  }'
~~~

### 数字人视频与人脸检测

数字人视频使用 `wan2.2-s2v`，由人物图片和人声音频生成口型同步视频；输出时长跟随输入音频，不单独传时长。

~~~bash
curl --request POST "$BASE_URL/ali/api/v1/services/aigc/image2video/video-synthesis" \
  --header "Authorization: Bearer $API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "wan2.2-s2v",
    "input": {
      "image_url": "https://example.com/portrait.jpg",
      "audio_url": "https://example.com/speech.mp3"
    },
    "parameters": {
      "resolution": "480P",
      "style": "speech"
    }
  }'
~~~

图片支持 JPG、JPEG、PNG、BMP、WEBP，宽高均为 400–7000 像素。音频支持 WAV、MP3，时长须小于 20 秒且文件小于 15 MB。
`parameters.resolution` 可选 `480P` 或 `720P`；`parameters.style` 可使用上游支持的表演风格。

人脸检测为同步接口，不创建任务。调用 `POST /ali/api/v1/services/aigc/image2video/face-detect`，模型固定为
`wan2.2-s2v-detect`，请求体使用 `input.image_url`。响应中的 `output.check_pass` 表示图片是否通过检测，
`output.humanoid` 表示是否检测到人像；接口直接返回检测结果，无需查询任务。

~~~bash
curl --request POST "$BASE_URL/ali/api/v1/services/aigc/image2video/face-detect" \
  --header "Authorization: Bearer $API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "wan2.2-s2v-detect",
    "input": {"image_url": "https://example.com/portrait.jpg"}
  }'
~~~

## 主要参数限制

| 模型 | 分辨率字段与可选档 | 时长限制 |
| --- | --- | --- |
| `wan3.0-video`、`wan3.0-video-prime` | `resolution`: `480P`、`720P`、`1080P` | 整数 2–30 秒；`-1` 表示智能时长 |
| `wan2.7-t2v`、`wan2.7-i2v`、`wan2.7-r2v`、`wan2.7-videoedit` | `resolution`: `720P`、`1080P` | 通常 2–15 秒；r2v 输入参考视频时 2–10 秒；videoedit 2–10 秒 |
| `wan2.6-t2v`、`wan2.6-i2v`、`wan2.6-i2v-flash` | `size`: 720P/1080P 对应像素尺寸 | 整数 2–15 秒 |

| `wan2.6-r2v`、`wan2.6-r2v-flash` | `size`: 720P/1080P 对应像素尺寸 | 整数 2–10 秒 |

| `wan2.2-t2v-plus` | `size`: 480P 或 1080P 对应像素尺寸 | 固定 5 秒 |
| `wan2.2-i2v-plus` | `size`: 480P 或 1080P 对应像素尺寸 | 固定 5 秒 |
| `wan2.2-i2v-flash` | `size`: 480P/720P/1080P 对应像素尺寸 | 固定 5 秒 |
| `wan2.2-kf2v-flash` | `resolution`: `480P`、`720P`、`1080P` | 固定 5 秒 |
| `wan2.2-s2v` | `resolution`: `480P` 或 `720P` | 跟随输入音频，音频须短于 20 秒；不要传 `duration` |

Wan 2.7 参考生视频包含参考视频时，输出时长为 2–10 秒；只含图片时为 2–15 秒。
分辨率值 `size` 使用像素尺寸字符串，例如 `1280*720`，不是 `720P` 或比例值。

## 查询任务

~~~bash
curl "$BASE_URL/ali/api/v1/tasks/$TASK_ID" \
  --header "Authorization: Bearer $API_KEY"
~~~

任务状态通常为 `PENDING`、`RUNNING`、`SUCCEEDED`、`FAILED`、`CANCELED` 或 `UNKNOWN`。成功时从 `output.video_url`
读取结果地址。Wan 没有专用任务列表接口；也可使用通用 Videos 查询接口。

~~~bash
curl "$BASE_URL/v1/videos/$TASK_ID" \
  --header "Authorization: Bearer $API_KEY"
~~~

## 下载视频

~~~bash
curl --fail --location "$BASE_URL/v1/videos/$TASK_ID/content" \
  --header "Authorization: Bearer $API_KEY" \
  --output generated.mp4
~~~

生成结果链接和任务记录有时效，请及时下载或转存。
