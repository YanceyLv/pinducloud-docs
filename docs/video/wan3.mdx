# 万相 Wan 视频生成 · 概述

> PinduCloud 提供本页所列接口。请求使用 PinduCloud API Key；模型开通情况以当前账号的可用模型为准，参数按本页对应型号的协议组织。

---

## 能力简介

万相视频生成支持以下任务类型：

| 任务类型 | 接口路径 | 说明 |
|:---|:---|:---|
| 文生视频 | `POST /ali/api/v1/services/aigc/video-generation/video-synthesis` | 根据文本提示词生成视频，wan2.7/wan2.6 支持自动配音与多镜头叙事。 |
| 图生视频 | `POST /ali/api/v1/services/aigc/video-generation/video-synthesis` | 以图片为首帧生成视频；支持首尾帧过渡、音频驱动（wan2.7）。 |
| 参考生视频 | `POST /ali/api/v1/services/aigc/video-generation/video-synthesis` | 以参考图/参考视频中的主体形象为基准生成视频，提示词中可用 `[Image 1]` 等语法引用。 |
| 视频编辑 | `POST /ali/api/v1/services/aigc/video-generation/video-synthesis` | 对已有视频按指令编辑（改色、换景、增删元素等），wan2.7-videoedit。 |
| 通用视频编辑 VACE | `POST /ali/api/v1/services/aigc/video-generation/video-synthesis` | 多图参考、视频重绘、局部编辑、视频延展、画面扩展五合一（wanx2.1-vace-plus）。 |
| 首尾帧生视频 | `POST /ali/api/v1/services/aigc/image2video/video-synthesis` | 输入首帧与尾帧图片，生成中间过渡视频（kf2v 系列）。 |
| 动作迁移 / 视频换人 | `POST /ali/api/v1/services/aigc/image2video/video-synthesis` | 让图片人物模仿视频动作（animate-move），或将视频中人物替换为图片人物（animate-mix）。 |
| 数字人视频 | `POST /ali/api/v1/services/aigc/image2video/video-synthesis` | 图片 + 音频生成数字人说话/演唱视频（wan2.2-s2v）。 |
| 人脸检测 | `POST /ali/api/v1/services/aigc/image2video/face-detect` | 数字人前置检测，校验图片人脸可用性（同步接口，立即返回）。 |
| 查询任务 | `GET /ali/api/v1/tasks/{task_id}` | 轮询任务状态及结果 |

除人脸检测为**同步接口**外，其余均为**异步任务**：创建任务后返回 `output.task_id`，需通过查询接口轮询状态；任务成功后响应中包含视频下载地址（有效期以实际返回地址为准），请及时下载或转存。

## 标准调用流程

```text
创建任务 (POST https://video.pinducloud.com.cn/ali/api/v1/services/aigc/video-generation/video-synthesis)
        │  返回 output.task_id
        ▼
查询状态 (GET https://video.pinducloud.com.cn/ali/api/v1/tasks/{task_id})   ← 轮询直至 SUCCEEDED
        │  返回 output.video_url
        ▼
下载视频文件
```

## 接口地址

> **路径规则**：在平台域名后追加渠道前缀 `/ali`，再拼接官方原始路径即可。
> 例如官方 `https://dashscope.aliyuncs.com/api/v1/services/aigc/video-generation/video-synthesis`
> → 平台 `https://video.pinducloud.com.cn/ali/api/v1/services/aigc/video-generation/video-synthesis`

## 鉴权

所有请求均通过 HTTP `Authorization` 头携带 Bearer Token 进行鉴权：

```text
Authorization: Bearer sk-your-pinducloud-token
```

`sk-your-pinducloud-token` 为您在平台控制台创建的接口密钥。

## 请求头

| 头部 | 必填 | 说明 |
|:---|:---:|:---|
| `Authorization` | 是 | `Bearer sk-your-pinducloud-token` |
| `Content-Type` | 条件必填 | POST 请求使用 `application/json`；GET 查询可省略 |

> 官方要求的 `X-DashScope-Async: enable` 头由平台自动补充，调用时**无需携带**；携带亦兼容。

## 模型总览

| 模型 | 能力 | 提交端点 | 主要规格 |
|:---|:---|:---|:---|
| `wan3.0-video`、`wan3.0-video-prime` | 文生视频、首尾帧或参考素材生成 | video-generation | 480P/720P/1080P，2–30 秒或智能时长；见 [Wan 3.0](/docs/video/wan/wan3) |
| `wan2.7-t2v`、`wan2.7-t2v-2026-06-12` | 文生视频 | video-generation | 720P/1080P，2–15 秒，有声，多镜头 |
| `wan2.7-i2v` | 图生视频（首帧 / 首尾帧 / 音频驱动） | video-generation | 720P/1080P，2–15 秒，有声 |
| `wan2.7-r2v` | 参考生视频 | video-generation | 720P/1080P，2–15 秒 |
| `wan2.7-videoedit` | 视频编辑 | video-generation | 按指令编辑，时长可继承输入视频 |
| `wan2.6-t2v` | 文生视频 | video-generation | 720P/1080P（size），2–15 秒 |
| `wan2.6-i2v`、`wan2.6-i2v-flash` | 图生视频 | video-generation | 480P–1080P（依模型），flash 为高性价比版 |
| `wan2.6-r2v` | 参考生视频 | video-generation | 720P/1080P |
| `wan2.5-t2v-preview`、`wan2.2-t2v-plus`、`wanx2.1-t2v-turbo`、`wanx2.1-t2v-plus` | 文生视频（早期版本） | video-generation | 分辨率档位依模型，固定或 5/10 秒 |
| `wanx2.1-vace-plus` | 通用视频编辑 VACE | video-generation | 固定 720P、5 秒 |
| `wan2.2-kf2v-flash`、`wanx2.1-kf2v-plus` | 首尾帧生视频 | image2video | flash：480P/720P/1080P；plus：720P |
| `wan2.2-animate-move`、`wan2.2-animate-mix` | 动作迁移 / 视频换人 | image2video | wan-std / wan-pro 两档 |
| `wan2.2-s2v` | 数字人视频 | image2video | 480P/720P，时长由音频决定 |
| `wan2.2-s2v-detect` | 人脸检测（同步） | face-detect | 即时返回检测结果 |

> 实际可用模型以平台控制台模型列表为准。

## 任务状态值

| 状态 | 含义 |
|:---|:---|
| `PENDING` | 任务排队中 |
| `RUNNING` | 任务处理中 |
| `SUCCEEDED` | 任务执行成功 |
| `FAILED` | 任务执行失败 |
| `CANCELED` | 任务已取消 |
| `UNKNOWN` | 任务不存在或状态未知；本站任务不存在时返回查询错误 |

状态流转：`PENDING → RUNNING → SUCCEEDED / FAILED`。

## 响应格式

所有异步接口使用统一的响应模式：

**创建任务响应** — 返回 `task_id` 用于轮询：

```jsonc
{
  "output": {
    "task_status": "PENDING",
    "task_id": "0385dc79-5ff8-4d82-bcb6-xxxxxx"
  },
  "request_id": "4909100c-7b5a-9f92-bfe5-xxxxxx"
}
```

**查询任务响应** — 返回任务状态、视频地址与用量：

```jsonc
{
  "request_id": "caa62a12-xxxx",
  "output": {
    "task_id": "eff1443c-xxxx",
    "task_status": "SUCCEEDED",
    "video_url": "https://dashscope-result-sh.oss-accelerate.aliyuncs.com/xxx.mp4?Expires=xxx"
  },
  "usage": {
    "duration": 5,
    "video_count": 1,
    "SR": 1080
  }
}
```

> 生成的视频地址有有效期，请及时下载或转存；任务记录的查询可用期以本站记录保留策略为准。
> 生成耗时通常为 1–5 分钟（依模型与时长），建议以 15 秒左右的间隔轮询查询接口。

## PinduCloud 调用说明

- 服务地址为 `https://video.pinducloud.com.cn`，鉴权使用本站创建的 API Key。
- 视频任务提交成功表示任务已受理；请保存响应返回的任务 ID，并使用同一用户的 API Key 查询最终状态。
- 本站查询仅返回当前用户可访问的任务；任务数据中的可选字段取决于任务服务返回的结果。
- 响应中的 `usage` 为用量信息；最终费用以本站使用日志为准。

## 用量与费用

视频创建请求提交成功后会预扣额度，任务完成后按本站配置的模型价格及可用用量信息结算。预扣额与最终费用可能不同，差额处理以使用日志为准；视频任务失败后退还该任务预扣额度。

`usage` 是任务服务返回的用量信息，不是金额。参考视频的输入时长是否计入、分辨率或音频是否采用不同价格，均以本站对应型号的计费规则为准，不能直接套用其他服务的价格。
