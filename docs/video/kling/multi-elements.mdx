# 多模态视频编辑

> PinduCloud 提供本页所列接口。请求使用 PinduCloud API Key；模型开通情况以当前账号的可用模型为准，参数按本页对应型号的协议组织。

POST 创建或管理请求可通过 `model_name` 选择账号已开通的可灵型号；未传时读取 `model`，两者都省略时使用 `kling-v1`。即使接口参数表未列出模型字段，也需确保账号已开通所选型号及对应能力。

### 初始化待编辑视频

```text
POST https://video.pinducloud.com.cn/kling/v1/videos/multi-elements/init-selection
```

使用"多模态视频编辑"功能时，需先对原始视频进行初始化处理。其中，在替换或删除现有视频中的元素时，需先标记视频中相关元素。

#### 请求头

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|:---|:---|:---:|:---|:---|
| `Content-Type` | string | 是 | application/json | 数据交换格式 |
| `Authorization` | string | 是 |  | `Bearer sk-your-pinducloud-token`，使用 PinduCloud API Key |

#### 请求体

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|:---|:---|:---:|:---|:---|
| `video_id` | string | 否 |  | 视频 ID，从历史作品中选择待编辑的视频，仅支持 30 天内生成的视频作品<br />- 仅支持 30 天内生成的视频作品<br />- 仅支持时长 ≥2 秒且 ≤5 秒，或 ≥7 秒且 ≤10 秒的视频<br />- 与 video_url 参数相关，不能同时为空，也不能同时有值 |
| `video_url` | string | 否 |  | 获取视频的 URL，上传时传视频下载链接，编辑选区时传接口返回的视频 URL<br />- 仅支持 MP4 和 MOV 格式<br />- 仅支持时长 ≥2 秒且 ≤5 秒，或 ≥7 秒且 ≤10 秒的视频<br />- 视频宽高尺寸需介于 720px（含）和 2160px（含）之间<br />- 仅支持上传 24、30 或 60fps 的视频<br />- 与 video_id 参数相关，不能同时为空，也不能同时有值 |

#### 请求示例

```bash
curl --request POST \
  --url https://video.pinducloud.com.cn/kling/v1/videos/multi-elements/init-selection \
  --header 'Authorization: Bearer sk-your-pinducloud-token' \
  --header 'Content-Type: application/json' \
  --data '{
    "video_id": "",
    "video_url": "https://v1-kling.klingai.com/kcdn/cdn-kcdn112452/kling-qa-test/animals-output-5s.mp4"
  }'
```

#### 响应示例

```jsonc
{
  "code": 0, // 错误码；错误详情见 message 字段
  "message": "string", // 错误信息
  "request_id": "string", // 请求ID，系统生成，用于跟踪请求、排查问题
  "data": {
    "status": 0, // 拒识码，非0为识别失败
    "session_id": "id", // 会话ID，会基于视频初始化任务生成，不会随编辑选区行为而改变，有效期24小时
    "final_unit_deduction": "string", // 任务服务原生积分信息；本站实际扣费以使用日志为准
    "fps": 30.0, // 解析后视频的帧数，在获取选区展示视频时需携参
    "original_duration": 1000, // 解析后视频的时长，在创建任务时需携参
    "width": 720, // 解析后视频的宽，暂无作用
    "height": 1280, // 解析后视频的高，暂无作用
    "total_frame": 300, // 解析后视频的总帧数，在创建任务时需携参
    "normalized_video": "url" // 初始化后的视频URL
}
}
```

### 增加视频选区

```text
POST https://video.pinducloud.com.cn/kling/v1/videos/multi-elements/add-selection
```

#### 请求头

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|:---|:---|:---:|:---|:---|
| `Content-Type` | string | 是 | application/json | 数据交换格式 |
| `Authorization` | string | 是 |  | `Bearer sk-your-pinducloud-token`，使用 PinduCloud API Key |

#### 请求体

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|:---|:---|:---:|:---|:---|
| `session_id` | string | 是 |  | 会话 ID，会基于视频初始化任务生成，不会随编辑选区行为而改变 |
| `frame_index` | int | 是 |  | 帧号<br />- 最多支持添加 10 个标记帧，即最多基于 10 帧标记视频选区<br />- 1 次仅支持标记 1 帧 |
| `points` | array | 是 |  | 点选坐标，用 x、y 表示<br />- 取值范围：[0, 1]，用百分比表示；[0, 1] 代表画面左上角<br />- 支持同时增加多个标记点，某一帧最多可标记 10 个点 |
|   `x` | float | 是 |  | X 坐标 [0-1] |
|   `y` | float | 是 |  | Y 坐标 [0-1] |

#### 请求示例

```bash
curl --request POST \
  --url https://video.pinducloud.com.cn/kling/v1/videos/multi-elements/add-selection \
  --header 'Authorization: Bearer sk-your-pinducloud-token' \
  --header 'Content-Type: application/json' \
  --data '{
    "session_id": "847570360458960960",
    "frame_index": 0,
    "points": [
      {
        "x": 0.7738498789346246,
        "y": 0.297142857142857
      }
    ]
  }'
```

#### 响应示例

```jsonc

  "data": {
    "status": 0, // 拒识码，非0为识别失败
    "session_id": "id", // 会话ID，会基于视频初始化任务生成，不会随编辑选区行为而改变，有效期24小时
    "final_unit_deduction": "string", // 任务服务原生积分信息；本站实际扣费以使用日志为准
    "res": {
      "frame_index": 0,
      "rle_mask_list": [{
        "object_id": 0,
        "rle_mask": {
          "size": [720, 1280],
          "counts": "string"
        },
        "png_mask": {
          "size": [720, 1280],
          "base64": "string"
        }
      }]
    }
  }
}
```

### 创建任务

```text
POST https://video.pinducloud.com.cn/kling/v1/videos/multi-elements
```

#### 请求头

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|:---|:---|:---:|:---|:---|
| `Content-Type` | string | 是 | application/json | 数据交换格式 |
| `Authorization` | string | 是 |  | `Bearer sk-your-pinducloud-token`，使用 PinduCloud API Key |

#### 请求体

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|:---|:---|:---:|:---|:---|
| `model_name` | string | 否 | kling-v1-6 | 模型名称<br />可选值: `kling-v1-6` |
| `session_id` | string | 是 |  | 会话 ID，会基于视频初始化任务生成，不会随编辑选区行为而改变 |
| `edit_mode` | string | 是 |  | 操作类型<br />可选值: `addition`, `swap`, `removal`<br />- addition：增加元素<br />- swap：替换元素<br />- removal：删除元素 |
| `image_list` | array | 否 |  | 裁剪后的参考图像<br />- 增加视频元素时：当前参数必填，可上传 1~2 张图片<br />- 编辑视频元素时：当前参数必填，仅可上传 1 张图片<br />- 删除视频元素时，当前参数无需填写<br />- 用 key:value 承载，如下：<br />- API 端无裁剪逻辑，请直接上传已选主体后的图片<br />- 支持传入图片 Base64 编码或图片 URL（确保可访问）<br />- 注意：若您使用 Base64 方式，请不要在 Base64 编码字符串前添加任何前缀（如 `data:image/png;base64,`），直接传递 Base64 编码后的字符串即可。<br />- 图片格式支持 .jpg / .jpeg / .png<br />- 图片文件大小不能超过 10MB，图片宽高尺寸不小于 300px，图片宽高比要在 1:2.5 ~ 2.5:1 之间 |
|   `image` | string | 是 |  | 图片 URL 或 Base64 字符串 |
| `prompt` | string | 是 |  | 正向文本提示词<br />- 用 &lt;&lt;&lt;xxx&gt;&gt;&gt; 的格式来特指某个视频或某张图片，如 &lt;&lt;&lt;video_1&gt;&gt;&gt;、&lt;&lt;&lt;image_1&gt;&gt;&gt;<br />- 为保证效果，提示词中需包含视频编辑所需的视频和图片（如有）<br />- 不能超过 2500 个字符<br />**推荐的 Prompt 模板：**<br /><br />**增加元素：**<br />- 中文：基于&lt;&lt;&lt;video_1&gt;&gt;&gt;中的原始内容，以自然生动的方式，将&lt;&lt;&lt;image_1&gt;&gt;&gt;中的【】，融入&lt;&lt;&lt;video_1&gt;&gt;&gt;的【】<br />- 英文：Using the context of &lt;&lt;&lt;video_1&gt;&gt;&gt;, seamlessly add [x] from &lt;&lt;&lt;image_1&gt;&gt;&gt;<br /><br />**替换元素：**<br />- 中文：使用&lt;&lt;&lt;image_1&gt;&gt;&gt;中的【】，替换&lt;&lt;&lt;video_1&gt;&gt;&gt;中的【】<br />- 英文：swap [x] from &lt;&lt;&lt;image_1&gt;&gt;&gt; for [x] from &lt;&lt;&lt;video_1&gt;&gt;&gt;<br /><br />**删除元素：**<br />- 中文：删除&lt;&lt;&lt;video_1&gt;&gt;&gt;中的【】<br />- 英文：Delete [x] from &lt;&lt;&lt;video_1&gt;&gt;&gt;<br /><br />注：中文的【】，英文的 [x]，是需要用户填写的部分 |
| `negative_prompt` | string | 否 |  | 负向文本提示词<br />- 不能超过 2500 个字符 |
| `mode` | string | 否 | std | 生成视频的模式<br />可选值: `std`, `pro`<br />- std：标准模式（标准），基础模式，性价比高<br />- pro：专家模式（高品质），高表现模式，生成视频质量更佳 |
| `duration` | string | 否 | 5 | 生成视频时长，单位 s<br />可选值: `5`, `10`<br />- 支持且仅支持生成 5s 和 10s 的视频<br />- 如生成 5s 时长视频，输入视频时长需 ≥2s 且 ≤5s<br />- 如生成 10s 时长视频，输入视频时长需 ≥7s 且 ≤10s |
| `watermark_info` | object | 否 |  | 是否同时生成含水印的结果<br />- 通过enabled参数定义，具体格式如下：<br />- true 为生成，false 为不生成<br />- 暂不支持自定义水印 |
| `callback_url` | string | 否 |  | 本次任务结果回调地址，发送给任务服务；是否投递及消息格式以实际服务行为为准<br />- 查询接口用于确认最终任务状态，请保留创建响应中的任务 ID |
| `external_task_id` | string | 否 |  | 自定义任务 ID<br />- 用户自定义任务 ID，传入不会覆盖系统生成的任务 ID，本站任务查询仍使用创建响应返回的公开任务 ID<br />- 请注意，单用户下需要保证唯一性 |

```jsonc
  { "image":"image_url" },
  { "image":"image_url" }
]
}
```
