# 可灵 AI 视频生成 · 概述

> PinduCloud 提供本页所列接口。请求使用 PinduCloud API Key；模型开通情况以当前账号的可用模型为准，参数按本页对应型号的协议组织。

---

## 能力简介

可灵 AI 视频生成支持以下任务类型：

| 任务类型 | 接口路径 | 说明 |
|:---|:---|:---|
| 文生视频 | `POST /kling/v1/videos/text2video` | 根据文本提示词生成视频 |
| 图生视频 | `POST /kling/v1/videos/image2video` | 以图片驱动生成视频 |
| 视频 Omni | `POST /kling/v1/videos/omni-video` | Omni 多模态视频生成，支持主体、图片、视频等多种输入 |
| 多图参考生视频 | `POST /kling/v1/videos/multi-image2video` | 多张参考图片生成视频 |
| 动作控制 | `POST /kling/v1/videos/motion-control` | 基于动作模板控制视频生成 |
| 多模态视频编辑 | `POST /kling/v1/videos/multi-elements` | 对视频中的元素进行替换、删除等编辑 |
| 视频延长 | `POST /kling/v1/videos/video-extend` | 延长已有视频时长 |
| 对口型 | `POST /kling/v1/videos/advanced-lip-sync` | 音频驱动口型同步视频生成 |
| 数字人 | `POST /kling/v1/videos/avatar/image2video` | 图片+音频生成数字人视频 |
| 文生音效 | `POST /kling/v1/audio/text-to-audio` | 根据文本描述生成音效 |
| 视频配音效 | `POST /kling/v1/audio/video-to-audio` | 为视频自动生成配套音效 |
| 语音合成 (TTS) | `POST /kling/v1/audio/tts` | 文本转语音 |
| 音色克隆 | `POST /kling/v1/general/custom-voices` | 自定义音色管理 |
| 图像识别 | `POST /kling/v1/videos/image-recognize` | 图片内容识别 |
| 主体管理 | `POST /kling/v1/general/advanced-custom-elements` | 自定义主体管理 |
| 视频特效 | `POST /kling/v1/videos/effects` | 基于模板生成视频特效 |

视频生成为**异步任务**：提交后立即返回 `task_id`，需通过查询任务接口轮询任务状态；任务成功后响应中包含视频下载地址，请及时下载或转存。

## 标准调用流程

```text
创建任务 (POST /kling/v1/videos/{endpoint})
        │  返回 task_id + task_status: "submitted"
        ▼
查询状态 (GET /kling/v1/videos/{endpoint}/{task_id})   ← 轮询直至 succeed 或 failed
        │  返回 task_result.videos[].url
        ▼
下载视频文件
```

## 接口地址

> **路径规则**：在平台域名后追加渠道前缀 `/kling`，再拼接可灵官方原始路径即可。
> 例如官方 `https://api-beijing.klingai.com/v1/videos/text2video` → 平台 `https://video.pinducloud.com.cn/kling/v1/videos/text2video`。

## 鉴权

所有请求均通过 HTTP `Authorization` 头携带 Bearer Token 进行鉴权：

```text
Authorization: Bearer sk-your-pinducloud-token
```

`sk-your-pinducloud-token` 为您在平台控制台创建的接口密钥。

## 请求头

| 头部 | 必填 | 说明 |
|:---|:---:|:---|
| `Authorization` | 是 | `Bearer sk-your-pinducloud-token` |
| `Content-Type` | 条件必填 | POST 请求使用 `application/json`；GET 查询可省略 |

## 模型概览

可灵 AI 支持以下模型版本：

| 模型 | 说明 |
|:---|:---|
| `kling-v3` | 3.0 视频生成型号，支持范围见对应接口 |
| `kling-v3-omni` | 3.0 Omni 多模态视频型号 |
| `kling-video-o1` | O1 Omni 多模态视频型号 |
| `kling-v2-6` | 2.6 视频型号，模式取值见对应接口 |
| `kling-v2-5-turbo` | Turbo 视频型号 |
| `kling-v2-1-master` | 2.1 Master 视频型号 |
| `kling-v2-master` | v2 系列早期版本 |
| `kling-v1-6` | v1.6 版本 |
| `kling-v1` | v1 基础版本 |

> 不同接口支持的模型列表可能有所差异，请以各接口文档中的说明为准。

## 任务状态值

| 状态 | 含义 |
|:---|:---|
| `submitted` | 已提交 |
| `processing` | 处理中 |
| `succeed` | 生成成功 |
| `failed` | 生成失败 |

## 响应格式

创建任务、单任务查询和同步管理接口的成功响应通常使用以下原生包装。字段是否返回取决于对应接口和任务阶段；错误响应不保证包含全部字段。

```jsonc
{
  "code": 0,
  "message": "string",
  "request_id": "string",
  "data": {} // 业务数据，字段详见对应接口
}
```

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `code` | Int | 错误码，0 表示成功 |
| `message` | String | 响应信息，成功时可能为空 |
| `request_id` | String | 请求 ID，用于跟踪、排查问题；部分响应为空或不返回 |
| `data` | Object / Array | 业务数据，形状随接口而异 |

异步任务的列表查询使用本站的分页结构，不能按上面的 `data` 包装解析：

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `items` | Array | 当前用户的任务列表 |
| `total` | Integer | 符合筛选条件的任务总数 |
| `page_num` / `page_size` | Integer | 当前页码和每页条数 |
| `items[].task_id` | String | 本站公开任务 ID |
| `items[].action` | String | 任务类型 |
| `items[].status` | String | 本站状态，如 `QUEUED`、`IN_PROGRESS`、`SUCCESS`、`FAILURE` |
| `items[].progress` / `items[].fail_reason` | String | 进度和失败原因 |
| `items[].created_at` | Integer | Unix 秒时间戳 |
| `items[].data` | Object | 任务服务返回的原生数据；尚未获取时可能不返回 |

官方预置音色和预置主体的列表为同步查询，仍返回其各自的原生响应。请按对应页面的示例区分。

## 回调通知

创建任务接口接受 `callback_url` 参数，并将其发送给任务服务。回调是否可用及通知格式以任务服务实际行为为准，最终状态请通过本站查询接口确认。

回调中可能包含任务服务自身的任务标识。查询本站任务时应使用创建响应中的公开 `task_id`；`external_task_id` 用于业务关联，原版查询接口不支持通过它查找本站任务。

## PinduCloud 调用说明

- 服务地址为 `https://video.pinducloud.com.cn`，鉴权使用本站创建的 API Key。
- 视频任务提交成功表示任务已受理；请保存响应返回的任务 ID，并使用同一用户的 API Key 查询最终状态。
- 本站查询仅返回当前用户可访问的任务；任务数据中的可选字段取决于任务服务返回的结果。
- 原生响应中的 `credits`、`final_unit_deduction` 等积分字段不代表本站最终扣费，实际费用以站内使用日志为准。

- `model_name` 用于选择账号可用的可灵模型，未提供时可使用 `model`；两者均省略时默认 `kling-v1`。音频、音色、图像识别和主体等接口也需确保账号存在对应路由模型。

视频生成、音色克隆和主体创建按任务方式处理；视频选区操作、人脸识别、图像识别、语音合成和素材删除等接口通常直接返回结果。同步响应未提供任务 ID 时，无需轮询，也不要自行构造任务查询地址。
