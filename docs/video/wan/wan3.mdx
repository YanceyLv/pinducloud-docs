# Wan 3.0 视频生成

`wan3.0-video` 和 `wan3.0-video-prime` 使用相同的创建和查询接口，支持文本、首尾帧或参考素材输入。调用前请确认当前 API Key 已开通所选型号及所需能力。

## 创建任务

```text
POST https://video.pinducloud.com.cn/ali/api/v1/services/aigc/video-generation/video-synthesis
```

### 请求头

| 参数 | 必填 | 说明 |
|:---|:---:|:---|
| `Authorization` | 是 | `Bearer sk-your-pinducloud-token`，替换为本站 API Key |
| `Content-Type` | 是 | `application/json` |

### 请求体

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|:---|:---|:---:|:---|:---|
| `model` | string | 是 | — | `wan3.0-video` 或 `wan3.0-video-prime` |
| `input` | object | 是 | — | 输入信息；`prompt` 与非空 `media` 至少提供一项 |
| `input.prompt` | string | 条件必填 | — | 文本提示词；纯文本生成时必须提供 |
| `input.media` | array | 否 | — | 素材数组，每项使用 `type` 和非空 `url`；数量和组合限制见下表 |
| `parameters` | object | 否 | — | 输出设置 |
| `parameters.resolution` | string | 否 | `1080P` | `480P`、`720P`、`1080P` |
| `parameters.ratio` | string | 否 | `adaptive` | `adaptive`、`16:9`、`9:16`、`1:1`、`4:3`、`3:4` |
| `parameters.duration` | integer | 否 | 5 | 2–30 秒；`-1` 表示由模型决定时长，不接受 0 |
| `parameters.prompt_extend` | boolean | 否 | true | 是否开启提示词扩展 |
| `parameters.seed` | integer | 否 | — | 随机种子，范围 -1 至 2147483647；固定种子不保证结果完全一致 |
| `parameters.watermark` | boolean | 否 | — | 是否添加水印；省略时采用模型服务的默认设置 |

上述参数是本站接受的请求范围。具体素材格式、生成效果和可用组合还须满足所选型号的要求。

## 素材类型与组合

| `type` | 最多数量 | 用途 |
|:---|:---:|:---|
| `first_frame` | 1 | 首帧图像 |
| `last_frame` | 1 | 尾帧图像，必须与首帧配合使用 |
| `reference_image` | 10 | 参考图片 |
| `reference_video` | 5 | 参考视频 |
| `reference_audio` | 5 | 参考音频 |
| `file` | 1 | 文件素材；仅在所选服务支持该类型时使用 |
| `link` | 1 | 链接素材；仅在所选服务支持该类型时使用 |

- 不传 `media` 时，必须提供非空 `prompt`。
- 首帧可以单独使用，也可以与尾帧配合；尾帧不能单独使用。
- 首尾帧不能与 `reference_image`、`reference_video`、`reference_audio`、`file` 或 `link` 混用。
- `file` 与 `link` 不能同时传入。
- 素材地址应能被模型服务访问。`example.com` 地址是占位符，须替换为实际素材地址。

## 请求示例

以下 curl 示例使用 Bash 语法。请替换 API Key 和素材地址；不要把示例中的占位符直接提交。

### 文生视频

```bash
curl --request POST \
  --url 'https://video.pinducloud.com.cn/ali/api/v1/services/aigc/video-generation/video-synthesis' \
  --header 'Authorization: Bearer sk-your-pinducloud-token' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "wan3.0-video",
    "input": {
      "prompt": "一只红色纸风筝缓缓飞过绿色田野，固定镜头。"
    },
    "parameters": {
      "resolution": "480P",
      "ratio": "4:3",
      "duration": 2
    }
  }'
```

### 首尾帧生成

```bash
curl --request POST \
  --url 'https://video.pinducloud.com.cn/ali/api/v1/services/aigc/video-generation/video-synthesis' \
  --header 'Authorization: Bearer sk-your-pinducloud-token' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "wan3.0-video-prime",
    "input": {
      "prompt": "镜头缓缓向前移动，平滑过渡到尾帧场景。",
      "media": [
        {"type": "first_frame", "url": "https://example.com/first-frame.jpg"},
        {"type": "last_frame", "url": "https://example.com/last-frame.jpg"}
      ]
    },
    "parameters": {
      "resolution": "480P",
      "duration": 2
    }
  }'
```

### 参考素材生成

```bash
curl --request POST \
  --url 'https://video.pinducloud.com.cn/ali/api/v1/services/aigc/video-generation/video-synthesis' \
  --header 'Authorization: Bearer sk-your-pinducloud-token' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "wan3.0-video",
    "input": {
      "prompt": "保持参考素材中的主体形象，生成一个缓慢转身的镜头。",
      "media": [
        {"type": "reference_image", "url": "https://example.com/reference.jpg"},
        {"type": "reference_video", "url": "https://example.com/reference.mp4"}
      ]
    },
    "parameters": {
      "resolution": "720P",
      "duration": 5
    }
  }'
```

## 创建响应与查询

创建成功后返回本站公开任务 ID：

```jsonc
{
  "request_id": "example-request-id",
  "output": {
    "task_id": "task-example",
    "task_status": "PENDING"
  }
}
```

使用该 `output.task_id` 调用 [查询任务](/docs/video/wan/query)：

```bash
curl --request GET \
  --url 'https://video.pinducloud.com.cn/ali/api/v1/tasks/task-example' \
  --header 'Authorization: Bearer sk-your-pinducloud-token'
```

将 `task-example` 替换为创建响应中的实际任务 ID。`SUCCEEDED` 表示完成，视频地址通常位于 `output.video_url`；`FAILED` 表示生成失败。可选字段以实际响应为准，下载链接有有效期，请及时保存。

## 用量与费用

提交任务时会预扣额度；任务完成后，本站按配置的模型价格和可用用量信息结算。对于 Wan 3.0，完整用量包含 `usage.input_video_duration` 和 `usage.output_video_duration`，输入视频时长与输出视频时长之和可用于结算。缺少完整用量时，不应自行把缺失字段当成 0 推算费用。

`parameters.duration` 是请求的输出时长，不能直接当作最终计费时长。特别是参考视频或智能时长任务，应以最终使用日志中的费用和差额记录为准。视频任务失败后退还该任务预扣额度。
