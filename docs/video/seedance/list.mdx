# 查询 Seedance 视频生成任务列表

列表接口只读取当前用户在 PinduCloud 提交的 Seedance 任务，不会把其他
用户的任务返回给调用方。过滤条件放在 Query 参数中，不能发送 JSON 请求体。

## 请求

~~~http
GET https://video.pinducloud.com.cn/doubao/api/v3/contents/generations/tasks
~~~

基础分页请求：

~~~bash
curl --get "$BASE_URL/doubao/api/v3/contents/generations/tasks" \
  --header "Authorization: Bearer $API_KEY" \
  --data-urlencode "page_num=1" \
  --data-urlencode "page_size=20"
~~~

按状态和模型过滤：

~~~bash
curl --get "$BASE_URL/doubao/api/v3/contents/generations/tasks" \
  --header "Authorization: Bearer $API_KEY" \
  --data-urlencode "page_num=1" \
  --data-urlencode "page_size=20" \
  --data-urlencode "filter.model=doubao-seedance-2-0-fast-260128" \
  --data-urlencode "filter.status=succeeded" \
  --data-urlencode "filter.service_tier=default"
~~~

## 查询参数

| 参数 | 类型和限制 | 默认值 | 说明 |
| --- | --- | --- | --- |
| page_num | 整数，1~500 | 1 | 页码 |
| page_size | 整数，1~500 | 20 | 每页条数 |
| filter.model | 单个字符串，最长 191 字符 | 空 | 按模型 ID过滤 |
| filter.status | queued、running、succeeded、failed、cancelled | 空 | 按状态过滤 |
| filter.service_tier | default、flex | default | 按服务等级过滤 |
| filter.task_ids | 可重复，最多 100 个 | 空 | 按 PinduCloud 任务 ID过滤 |

过滤条件之间按 AND 关系处理。未传 filter.model 时表示所有当前用户可见的
Seedance 模型。列表默认使用近 7 天的任务窗口，过期的任务记录不会被重新查询。
`filter.service_tier` 只是对已保存任务的字段进行筛选，不代表当前
Seedance 2.0 创建入口可以传入 `service_tier`。

重复任务 ID的写法：

~~~bash
curl --get "$BASE_URL/doubao/api/v3/contents/generations/tasks" \
  --header "Authorization: Bearer $API_KEY" \
  --data-urlencode "filter.task_ids=task_gateway_doubao_01" \
  --data-urlencode "filter.task_ids=task_gateway_doubao_02"
~~~

## 响应

~~~json
{
  "items": [
    {
      "id": "task_gateway_doubao_01",
      "model": "doubao-seedance-2-0-fast-260128",
      "status": "succeeded",
      "resolution": "720p",
      "duration": 5,
      "content": {
        "video_url": "https://cdn.example.com/video.mp4"
      },
      "usage": {
        "completion_tokens": 108000,
        "total_tokens": 108000
      }
    },
    {
      "id": "task_gateway_doubao_02",
      "model": "doubao-seedance-2-0-fast-260128",
      "status": "running"
    }
  ],
  "total": 2
}
~~~

items 中每项的任务字段与[单任务查询](./query)相同。处理中任务没有视频
地址，成功任务的 URL仍然可能随签名有效期过期。

## 参数错误

以下情况会返回 400：页码或每页数量不在范围内、同一个单值参数重复出现、状态
值不受支持、任务 ID为空或超过数量限制，以及向列表接口发送请求体。
