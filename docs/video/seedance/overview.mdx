# 豆包 Seedance 视频生成

这组接口通过 Seedance 模型提交文生视频、图生视频和多模态参考视频任务。
请求体使用 Ark/Seedance 的 `content` 结构，任务结果通过异步查询接口取得。
本页说明 Seedance 2.0 标准版、Fast、Mini 和 2.5 的接口规则。不同版本有各自的
参数限制，不能套用同一套规则。模型是否可调用，以当前 API Key 的模型列表为准。

## 服务地址

~~~text
https://video.pinducloud.com.cn
~~~

## 接口列表

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | /doubao/api/v3/contents/generations/tasks | 创建异步视频任务 |
| GET | /doubao/api/v3/contents/generations/tasks/:task_id | 查询单个任务 |
| GET | /doubao/api/v3/contents/generations/tasks | 分页查询当前用户任务 |
| DELETE | /doubao/api/v3/contents/generations/tasks/:task_id | 取消或删除任务 |
| POST | /v1/seedance/validation-sessions | 创建真人认证会话 |
| GET | /v1/seedance/validation-sessions/:id | 查询真人认证进度和素材组 |
| POST | /doubao/v2/assets?Action=CreateVisualValidateSession&Version=2024-01-01 | Action 格式创建真人认证会话 |
| POST | /doubao/v2/assets?Action=GetVisualValidateResult&Version=2024-01-01 | Action 格式查询真人认证结果 |

素材组与媒体的增删改查见[私域素材库](./private-assets)，真人认证的完整流程见
[真人认证与人像素材](./human-verification)。已有 OpenAI 客户端可参考
[兼容接口](./compatible)。以上路径均相对于本页服务地址，直接按示例调用。

~~~bash
export BASE_URL="https://video.pinducloud.com.cn"
export API_KEY="sk-your-api-key"
~~~

所有程序接口使用 `Authorization: Bearer $API_KEY`。示例采用 Bash 语法，
JSON 请求还需设置 `Content-Type: application/json`。

### 任务场景

| 场景 | content 组成 | 适用模型 |
| --- | --- | --- |
| 文生视频 | 文本项 | 已开放的对应模型 |
| 首帧图生视频 | 文本项 + 一张首帧图 | 由对应模型的输入能力决定 |
| 首尾帧图生视频 | 文本项 + `first_frame` 和 `last_frame` | 2.0 标准版、Fast、Mini 的接口均接受；生成以模型处理结果为准 |
| 多模态参考生成 | 文本项 + 参考图/视频/音频 | 当前 2.0 三个模型的 `content` 入口 |
| 有声视频 | `generate_audio: true` | 当前 2.0 三个模型 |
| Draft 样片 | `draft: true` | 当前文档保留 1.5 pro 流程；2.0 入口拒绝 |

首帧/首尾帧和多模态参考是互斥的输入场景。不要在同一个请求中同时混用
first_frame、last_frame 与 reference_* 角色。

## 模型与分辨率

接口识别以下模型名称；识别名称不表示当前 API Key 已开通该模型。可通过
`GET /v1/models` 查询可用列表。

~~~text
doubao-seedance-1-0-pro-250528
doubao-seedance-1-0-lite-t2v
doubao-seedance-1-0-lite-i2v
doubao-seedance-1-5-pro-251215
doubao-seedance-2-0-260128
doubao-seedance-2-0-fast-260128
doubao-seedance-2-0-mini-260615
doubao-seedance-2-5-260628
~~~

各模型的输出分辨率限制如下：

| 模型 | 可用分辨率 |
| --- | --- |
| doubao-seedance-2-0-fast-260128 | 480p、720p |
| doubao-seedance-2-0-mini-260615 | 480p、720p |
| doubao-seedance-2-0-260128 | 480p、720p、1080p、4k |
| doubao-seedance-2-5-260628 | 480p、720p、1080p；不支持 4k |
| 上述 1.0 和 1.5 模型 | 480p、720p、1080p |

Fast 和 Mini 模型不能传 `1080p`、`4k` 或等价的高分辨率尺寸。未传 `resolution`
时，Fast/Mini 按 `720p` 进行预估，标准版按 `1080p` 进行预估；实际结果以查询
响应的 `resolution` 字段为准。2.5 默认按 `1080p` 预估，不能通过 `4K`、
`3840x2160` 等写法请求 4K；兼容接口的 `size` 也遵守同一限制。

## 三个 2.0 模型的字段边界

下表说明本站 `/doubao/api/v3/contents/generations/tasks` 入口的行为，并单独标出
已知的模型限制。“本站当前拒绝”表示本站会在提交前返回 400；没有标注为模型限制
的项目，不应推断其他 Seedance 版本也有相同限制。

| 字段或能力 | 标准版 `doubao-seedance-2-0-260128` | Fast / Mini | 本站行为 |
| --- | --- | --- | --- |
| `resolution` | `480p`、`720p`、`1080p`、`4k` | `480p`、`720p` | Fast/Mini 的高分辨率请求返回 400 |
| `duration` | `-1` 或 4~15 的整数 | `-1` 或 4~15 的整数 | 其他值返回 400 |
| `content` 参考媒体 | 参考图、参考视频、参考音频 | 同左 | 媒体角色和数量必须符合请求规则 |
| `frames` | 本站当前拒绝 | 本站当前拒绝 | 不代表其他 Seedance 版本都不支持 |
| `service_tier` | 本站当前拒绝 | 本站当前拒绝 | 列表过滤参数仍可使用 `default`/`flex` |
| `draft: true`、`draft_task` | 本站当前拒绝 | 本站当前拒绝 | `draft: false` 可传，2.0 不使用 Draft 流程 |
| `camera_fixed` | 本站拒绝；标准版不支持 | 本站拒绝 | 返回 400 |
| `output_format` | 本站只接受 `mp4`；标准版不支持 `mov` | 本站只接受 `mp4` | 返回 400 |
| `generate_audio` | 支持 | 支持 | 显式 `false` 用于请求无声视频 |
| `return_last_frame` | 支持 | 支持 | 结果可能包含 `last_frame_url` |
| `seed`、`priority` | 按字段范围传递 | 按字段范围传递 | 查询结果以实际返回值为准 |
| `tools` | 可传 `web_search` 工具 | 可传 | 是否实际执行以任务结果为准 |

`frames`、`service_tier`、`draft: true` 和 `draft_task` 是本站当前 2.0 入口的限制，
不要根据查询结果中出现的同名字段反推创建接口可以接受它们。`service_tier` 出现
在列表过滤中，只表示可以筛选已保存任务的字段。

`seed` 是请求值和实际使用值的两个概念。本站会保留并发送调用方提供的值，查询
结果中的 `seed` 是任务返回值；如果模型自行调整，本站不会改写回显结果。

## 结果与保留时间

创建成功后返回一个公开任务 ID，查询成功时视频地址在
content.video_url 中，可能还会有 content.last_frame_url。视频签名地址是
临时地址，客户端应在地址有效期内下载或转存。任务列表仅覆盖最近 7 天；这不等于
视频下载地址具有 7 天有效期，也不表示单任务查询保证保留 7 天。

## 私域素材库

程序可使用视频生成的 API Key 调用 `/v1/seedance` 素材管理接口。同一用户的
有效 Key 共享该用户的素材组和媒体，包括控制台已上传的数据；创建普通素材组时
通过 `model` 指定计划使用的模型。

Seedance 支持使用 PinduCloud 私域素材库中的图片、视频和音频。上传完成并审核
为 `Active` 后，从素材列表取得 `asset_id`，在标准 `content` 媒体项的 URL 字段中
使用 `asset://<AssetId>` 引用素材；`asset_id` 原值不能直接作为 URL。
有效且模型服务可访问的 `preview_url` 也可以作为普通公网地址输入，媒体仍须符合
所选模型的要求；临时地址可能过期，长期复用优先使用 `asset://` 引用。

完整流程、上传接口和示例见[使用 Seedance 私域素材库](./private-assets)。

普通素材组的类型为 `AIGC`；已认证真人素材组的类型为 `LivenessFace`，必须先完成
真人认证。控制台分别展示两类素材组。认证成功后还需要上传对应人像并等待素材审核，
认证通过本身不会生成可引用的 `asset_id`。

`Active` 表示素材处理完成，生成仍需满足目标模型的权限和输入要求。若返回素材同步
错误，请保留素材 ID、模型名称和 request ID 排查。
