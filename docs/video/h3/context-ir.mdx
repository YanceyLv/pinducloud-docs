# 创建 H3-Context-IR 任务

H3-Context-IR 会理解文本与多模态上下文，生成更完整的结构化视频提示词。它本身
不会生成视频，也不会返回视频 URL；输出的增强提示词可直接用于 H3 视频生成，
也可作为视频再生成所需的最终 `prompt`。这是异步任务接口，创建成功只表示任务
已受理。

## 请求

~~~http
POST https://video.pinducloud.com.cn/hailuo/v2/h3_context_ir
~~~

~~~bash
curl --request POST "$BASE_URL/hailuo/v2/h3_context_ir" \
  --header "Authorization: Bearer $API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "MiniMax-H3",
    "content": [
      {"type": "text", "text": "把这段想法扩展成电影级的多镜头视频提示词"},
      {
        "type": "image_url",
        "role": "reference_image",
        "image_url": {"url": "https://cdn.example.com/reference.png"}
      }
    ],
    "duration": 5,
    "ratio": "16:9"
  }'
~~~

## 参数

| 字段 | 类型 | 必填 | 取值或范围 | 说明 |
| --- | --- | --- | --- | --- |
| model | string | 是 | MiniMax-H3 | 固定模型 |
| content | array | 是 | 与 H3 生成相同的多模态项 | 必须有非空 text |
| duration | integer | 是 | 4~15 | 目标视频时长，秒 |
| ratio | string | 否 | H3 生成接口的比例枚举 | 目标画面比例 |
| callback_url | string | 否 | 公网可访问地址 | 可选状态回调 |

本接口没有 `resolution` 参数。`duration` 表示生成提示词所对应的目标视频时长，
取值仍为 4~15 秒；`ratio` 的默认值和媒体组合规则沿用[H3 视频生成接口](./create)。
本接口的结果是文本，不会产生视频秒数或输入图片费用。

本接口的 `callback_url` 同样不构成受理前的可达性门槛；回调行为和客户端处理方式
见[回调地址](./create#回调地址)。

## 任务结果

创建成功先返回异步任务 ID：

~~~json
{
  "task_id": "task_gateway_ir_01"
}
~~~

完成后调用查询接口，成功任务的关键字段如下：

~~~json
{
  "task": {
    "id": "task_gateway_ir_01",
    "model": "MiniMax-H3",
    "status": "succeeded",
    "content": {
      "prompt": "integrated_multimodal_description: [Shot 1] ..."
    },
    "task_type": "h3_context_ir",
    "modality": "text",
    "usage": {
      "total_tokens": 9090,
      "prompt_tokens": 5664,
      "completion_tokens": 3426
    }
  }
}
~~~

task.content.prompt 是增强后的完整提示词。调用视频生成时，把它作为一个
content 文本项传入：

~~~json
{
  "model": "MiniMax-H3",
  "content": [
    {"type": "text", "text": "integrated_multimodal_description: [Shot 1] ..."}
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "16:9"
}
~~~

Context-IR 任务按实际 `prompt_tokens` 与 `completion_tokens` 分开结算，两个字段
使用管理员分别配置的 Token 单价。提交阶段不会按视频秒数、输入图片或输入视频
预扣；任务失败时不产生最终 Token 费用。
