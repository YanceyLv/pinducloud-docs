# 查询 MiniMax-H3 任务列表

列表接口返回当前用户在 PinduCloud 创建的 H3 任务，包含普通视频生成、视频再生成
和 Context-IR。它使用 Query 参数筛选，不接收 JSON 请求体。

## 请求

~~~http
GET https://video.pinducloud.com.cn/hailuo/v2/query/video_generation
~~~

~~~bash
curl --get "$BASE_URL/hailuo/v2/query/video_generation" \
  --header "Authorization: Bearer $API_KEY" \
  --data-urlencode "page_num=1" \
  --data-urlencode "page_size=20" \
  --data-urlencode "filter.status=succeeded" \
  --data-urlencode "filter.task_type=generation"
~~~

## 查询参数

| 参数 | 类型和限制 | 默认值 | 说明 |
| --- | --- | --- | --- |
| page_num | 整数，1~100000 | 1 | 页码 |
| page_size | 整数，1~100 | 20 | 每页数量 |
| filter.model | 只能为 MiniMax-H3 | 空 | 按模型过滤 |
| filter.status | queued、running、succeeded、failed、cancelled | 空 | 按状态过滤 |
| filter.task_type | generation、regeneration、h3_context_ir | 空 | 按任务类型过滤 |
| filter.task_ids | 可重复，最多 100 个 | 空 | 按网关任务 ID过滤 |

列表查询结果按当前用户隔离。重复传入任务 ID：

~~~bash
curl --get "$BASE_URL/hailuo/v2/query/video_generation" \
  --header "Authorization: Bearer $API_KEY" \
  --data-urlencode "filter.task_ids=task_gateway_h3_01" \
  --data-urlencode "filter.task_ids=task_gateway_h3_02"
~~~

## 响应

~~~json
{
  "items": [
    {
      "id": "task_gateway_h3_01",
      "model": "MiniMax-H3",
      "status": "succeeded",
      "task_type": "generation",
      "modality": "video",
      "resolution": "2K",
      "duration": 5,
      "content": {"url": "https://cdn.example.com/output.mp4"},
      "usage": {
        "total_seconds": 5,
        "input_seconds": 0,
        "output_seconds": 5,
        "input_image_count": 0
      }
    },
    {
      "id": "task_gateway_ir_01",
      "model": "MiniMax-H3",
      "status": "running",
      "task_type": "h3_context_ir",
      "modality": "text"
    }
  ],
  "total": 2
}
~~~

items 中每项使用与[查询单个任务](./query)相同的任务结构；任务未完成时不应
假定 content 或 usage 已存在。
