# 可灵 AI 视频生成（新版接口）· 概述

> PinduCloud 提供本页所列接口。请求使用 PinduCloud API Key；模型开通情况以当前账号的可用模型为准，参数按本页对应型号的协议组织。
> 新版接口与经典接口（`/kling/v1/videos/*`）并行提供、互不影响，已接入经典接口的用户无需迁移。

---

## 能力简介

新版接口按能力划分端点，模型名直接写在 URL 路径中：

| 能力 | 接口路径 | 支持模型 | 说明 |
|:---|:---|:---|:---|
| 文生视频 | `POST /kling/text-to-video/{model}` | `kling-3.0`、`kling-3.0-turbo`、`kling-2.6`、`kling-2.5-turbo` | 根据文本提示词生成视频 |
| 图生视频 | `POST /kling/image-to-video/{model}` | `kling-3.0`、`kling-3.0-turbo`、`kling-2.6`、`kling-2.5-turbo` | 以图片驱动生成视频 |
| Omni 视频生成 | `POST /kling/omni-video/{model}` | `kling-3.0-omni`、`kling-o1` | 多模态全能视频生成，支持图片、视频、主体、音色等输入 |
| 动作控制 | `POST /kling/motion-control/{model}` | `kling-3.0`、`kling-2.6` | 参考视频驱动人物动作生成 |
| 查询任务 | `GET /kling/tasks` | — | 统一任务查询，支持批量与自定义任务 ID |

视频生成为**异步任务**：提交后立即返回任务 `id`，需通过查询任务接口轮询任务状态；任务成功后响应中包含视频下载地址，请及时下载或转存。

## 标准调用流程

```text
创建任务 (POST /kling/{capability}/{model})
        │  返回 data.id + status: "submitted"
        ▼
查询状态 (GET /kling/tasks?task_ids={id})   ← 轮询直至 succeeded 或 failed
        │  返回 outputs[].url
        ▼
下载视频文件
```

## 接口地址

> **路径规则**：在平台域名后追加渠道前缀 `/kling`，再拼接可灵官方新版路径即可（新版路径无 `/v1` 前缀）。
> 例如官方 `https://api-beijing.klingai.com/text-to-video/kling-3.0` → 平台 `https://video.pinducloud.com.cn/kling/text-to-video/kling-3.0`。

## 鉴权

所有请求均通过 HTTP `Authorization` 头携带 Bearer Token 进行鉴权：

```text
Authorization: Bearer sk-your-pinducloud-token
```

`sk-your-pinducloud-token` 为您在平台控制台创建的接口密钥。

## 请求头

| 头部 | 必填 | 说明 |
|:---|:---:|:---|
| `Authorization` | 是 | `Bearer sk-your-pinducloud-token` |
| `Content-Type` | 条件必填 | POST 请求使用 `application/json`；GET 查询可省略 |

## 模型概览

| 模型（URL 段名） | 说明 |
|:---|:---|
| `kling-3.0` | 旗舰模型，支持多镜头、原生音频、最高 4K 清晰度 |
| `kling-3.0-turbo` | 3.0 加速版，参数范围与 3.0 有差异 |
| `kling-3.0-omni` | 3.0 全能版，多模态输入（图片/视频/主体/音色） |
| `kling-o1` | 多模态视频模型，支持参考视频输入 |
| `kling-2.6` | 高性价比模型，支持原生音频与指定音色 |
| `kling-2.5-turbo` | Turbo 视频型号 |

> 不同能力支持的模型与参数范围有差异，请以各接口文档中的说明为准。

## 通用默认值

视频生成接口采用以下协议默认值；动作控制的专用设置另见下方说明：

| 参数 | 默认值 |
|:---|:---|
| `settings.resolution` | `720p` |
| `settings.duration` | `5`（秒） |
| `settings.audio` | `off` |
| `settings.aspect_ratio` | `16:9` |

动作控制的 `settings.audio` 默认为 `original`，且必须传入 `settings.character_orientation`。其输出时长由参考视频决定，不使用生成接口的默认 5 秒作为输出长度。

## 任务状态值

| 状态 | 含义 |
|:---|:---|
| `submitted` | 已提交 |
| `processing` | 处理中 |
| `succeeded` | 生成成功 |
| `failed` | 生成失败 |

## 响应格式

创建任务的成功响应通常采用以下结构。查询接口的 `data` 为数组，字段详见[查询任务](/docs/video/kling-new/query)。鉴权、请求校验及任务服务错误的结构可能不同，请同时检查 HTTP 状态码和错误内容。

```jsonc
{
  "code": 0,
  "message": "string",
  "request_id": "string",
  "data": {} // 业务数据，字段详见对应接口
}
```

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `code` | Int | 错误码，0 表示成功 |
| `message` | String | 响应信息，成功时可能为空 |
| `request_id` | String | 请求 ID，用于跟踪、排查问题；部分响应为空或不返回 |
| `data` | Object / Array | 创建任务为对象，查询列表为数组 |

## 回调通知

创建任务接口接受 `options.callback_url` 参数，并将其发送给任务服务。回调是否可用及通知格式以任务服务实际行为为准，最终状态请通过本站查询接口确认。

回调中可能包含任务服务自身的任务标识，不能直接当作本站公开任务 ID 使用。请保存创建响应中的 `data.id`，并在需要时使用 `options.external_task_id` 关联业务记录。

## PinduCloud 调用说明

- 服务地址为 `https://video.pinducloud.com.cn`，鉴权使用本站创建的 API Key。
- 视频任务提交成功表示任务已受理；请保存响应返回的任务 ID，并使用同一用户的 API Key 查询最终状态。
- 本站查询仅返回当前用户可访问的任务；任务数据中的可选字段取决于任务服务返回的结果。
- 原生响应中的 `credits`、`final_unit_deduction` 等积分字段不代表本站最终扣费，实际费用以站内使用日志为准。
