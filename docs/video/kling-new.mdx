# Kling 新版视频接口

本页说明 Kling 新版异步视频接口。新版路径不含 `/v1`，模型名位于路径末尾；它与原版路径并行，
请求时应使用当前 API Key 可用的模型名。

## 服务地址与鉴权

~~~bash
export BASE_URL="https://video.pinducloud.com.cn"
export API_KEY="sk-your-api-key"
export TASK_ID="task-id-from-creation-response"
~~~

请求头使用 `Authorization: Bearer $API_KEY` 和 `Content-Type: application/json`。

## 接口与模型

| 能力 | 创建路径 | 模型 |
| --- | --- | --- |
| 文生视频 | `/kling/text-to-video/{model}` | `kling-3.0`、`kling-3.0-turbo`、`kling-2.6`、`kling-2.5-turbo` |
| 图生视频 | `/kling/image-to-video/{model}` | `kling-3.0`、`kling-3.0-turbo`、`kling-2.6`、`kling-2.5-turbo` |
| Omni 多模态生成 | `/kling/omni-video/{model}` | `kling-3.0-omni`、`kling-o1` |
| 动作控制 | `/kling/motion-control/{model}` | `kling-3.0`、`kling-2.6` |
| 查询任务 | `GET /kling/tasks` | 所有新版任务 |
| 查询单个任务 | `GET /v1/videos/{task_id}` | 使用创建响应中的 `data.id` |
| 下载视频 | `GET /v1/videos/{task_id}/content` | 使用创建响应中的 `data.id` |

模型和能力的组合有差异；只有 `/v1/models` 中列出的模型才可由当前 API Key 调用。

## 通用配置

创建请求支持 `settings` 和 `options`：

| 字段 | 说明 |
| --- | --- |
| `settings.resolution` | 清晰度。常用值为 `720p`、`1080p`；`4k` 仅部分模型支持 |
| `settings.aspect_ratio` | 文生视频画幅，可选 `16:9`、`9:16`、`1:1`；图生视频按首帧画幅生成 |
| `settings.duration` | 输出时长。Kling 3.0 系列为 3 到 15 秒；部分 2.x 模型只接受 5 或 10 秒 |
| `settings.audio` | 音频模式。`native` 生成声音，`off` 输出无声视频；仅部分模型支持 `native` |
| `settings.multi_shot` | 是否生成多镜头，仅部分 3.0 模型支持 |
| `options.callback_url` | 任务状态变化时的回调地址 |
| `options.external_task_id` | 用户自定义查询 ID；同一用户下应保持唯一 |
| `options.watermark_info.enabled` | 是否生成带水印的结果，默认 `false` |

`kling-3.0` 和 `kling-3.0-omni` 的多镜头提示词可使用 `镜头 n, 时长, 描述;` 格式，最多 6 个镜头，
各镜头时长之和须与总时长一致。参数支持范围以模型和调用渠道的实际能力为准。

## 文生视频

~~~bash
curl --request POST "$BASE_URL/kling/text-to-video/kling-3.0" \
  --header "Authorization: Bearer $API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "prompt": "A quiet seaside at sunset, waves move gently toward the shore.",
    "settings": {
      "resolution": "720p",
      "aspect_ratio": "16:9",
      "duration": 5,
      "audio": "off",
      "multi_shot": false
    }
  }'
~~~

`prompt` 为必填项。文本中可描述主体、动作、场景、镜头和音频；模型支持的提示词长度因型号而异。

## 图生视频

通过 `contents` 提供提示词及图像素材。图像可使用 URL 或 Base64；可选的 `last_frame` 用于首尾帧生成。

~~~bash
curl --request POST "$BASE_URL/kling/image-to-video/kling-3.0" \
  --header "Authorization: Bearer $API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "contents": [
      {"type": "prompt", "text": "The camera slowly moves closer as the person turns toward the light."},
      {"type": "first_frame", "url": "https://example.com/first.jpg"}
    ],
    "settings": {
      "resolution": "720p",
      "duration": 5,
      "audio": "off"
    }
  }'
~~~

图片支持 JPG、JPEG、PNG；每张不超过 50 MB，宽高至少 300 像素，宽高比在 `1:2.5` 到 `2.5:1` 之间。
参考图必须能由上游任务服务访问。首尾帧模式需要同时提供 `first_frame` 和 `last_frame`；不同模型的清晰度限制不同。

## Omni 多模态生成

Omni 使用同一路径组合文本、首尾帧、参考图、参考视频、待编辑视频或主体素材。每个 `contents` 元素按
`type` 指定输入类型；提示词可用 `id` 为素材命名，并通过 `@id` 引用。

~~~bash
curl --request POST "$BASE_URL/kling/omni-video/kling-3.0-omni" \
  --header "Authorization: Bearer $API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "contents": [
      {"type": "prompt", "text": "Continue the scene and keep the movement of @video_1."},
      {"type": "feature_video", "url": "https://example.com/reference.mp4", "id": "video_1"}
    ],
    "settings": {
      "resolution": "720p",
      "duration": 5,
      "audio": "off",
      "multi_shot": true
    }
  }'
~~~

视频素材仅支持 MP4、MOV 和 HTTP(S) 地址。可添加的图片、视频与主体数量，以及 `audio`、`multi_shot` 的组合，
取决于所选模型；例如使用参考视频时，部分模型会限制音频或多镜头选项。

## 动作控制

动作控制需要一张形象参考图、一段动作参考视频和 `settings.character_orientation`。

~~~bash
curl --request POST "$BASE_URL/kling/motion-control/kling-3.0" \
  --header "Authorization: Bearer $API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "contents": [
      {"type": "prompt", "text": "Keep the character expression natural while following the motion."},
      {"type": "image", "url": "https://example.com/person.jpg"},
      {"type": "video", "url": "https://example.com/motion.mp4"}
    ],
    "settings": {
      "character_orientation": "video",
      "resolution": "720p",
      "audio": "original"
    }
  }'
~~~

`character_orientation` 为 `image` 或 `video`。前者参考图片中人物朝向，动作视频最长 10 秒；后者参考视频人物朝向，
动作视频最长 30 秒。输出时长由可识别的连续动作决定，不在请求中设置 `duration`。图片和动作视频需清晰展示人物，
避免遮挡、快速剪辑或多人主体。

## 查询任务

新版任务列表通过 `/kling/tasks` 查询。`task_ids` 使用创建响应的 `data.id`；也可使用创建时传入的
`options.external_task_id`，并通过复数查询参数 `external_task_ids` 查找。`task_ids` 和 `external_task_ids`
不能同时使用；每个参数最多传 100 个以逗号分隔的 ID。

~~~bash
curl --get "$BASE_URL/kling/tasks" \
  --header "Authorization: Bearer $API_KEY" \
  --data-urlencode "task_ids=$TASK_ID"
~~~

任务状态为 `submitted`、`processing`、`succeeded` 或 `failed`。成功后从 `data[].outputs[].url` 获取视频地址；
下载链接有时效，请及时下载或转存。

## 下载视频

~~~bash
curl --fail --location "$BASE_URL/v1/videos/$TASK_ID/content" \
  --header "Authorization: Bearer $API_KEY" \
  --output generated.mp4
~~~
