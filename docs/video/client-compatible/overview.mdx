# 豆包 Seedance 兼容接口

本组接口用于视频任务、素材库和真人认证。接口路径包含固定的 `/doubao` 前缀。

## 服务地址

示例中的 `BASE_URL` 是服务根地址，不包含 `/doubao`：

~~~bash
export BASE_URL="https://video.example.com"
export API_KEY="YOUR_API_KEY"
~~~

请替换为实际服务地址和自己的 API Key。`MODEL_ID` 表示当前 Key 可用的模型名称。

如果客户端自行拼接 `/api/v3/...`、`/api/assets/...` 等路径，可将客户端基础地址设为
`https://video.example.com/doubao`。生成签名时必须使用最终请求地址。

## 调用流程

1. 使用自己的 API Key，或为该 Key 签发 AK/SK。
2. 普通素材先创建素材组；真人素材先完成本人认证，取得认证组。
3. 登记或上传素材，查询至 `ACTIVE` 后使用。
4. 创建视频任务并保存响应中的 `id`。
5. 查询任务至终态；成功后读取 `content.video_url`。

素材引用格式为 `asset://<素材 ID>`。同一账号的有效 Key 共享素材记录，调用时仍检查
Key 的分组、模型、IP 和额度权限。素材可用于哪些模型，还取决于素材审核状态和已完成的同步；
真人素材受认证范围约束。

## 请求与响应

除文件上传和下载外，请求及响应使用 JSON。文件上传使用 `multipart/form-data`，
下载返回二进制流。需要鉴权的业务接口支持 Bearer 和本站签发的 AK/SK。

视频创建成功仅表示任务已受理。素材创建成功也可能仍在审核，不能把 HTTP 200 当作生成或审核成功。

| HTTP 状态 | 常见含义 |
| --- | --- |
| 200 | 请求成功；异步操作仍需读取业务状态 |
| 400 | 请求参数或参数组合不合法 |
| 401 | 凭据缺失、失效或签名错误 |
| 403 | 权限、IP 或额度条件不满足 |
| 404 | 资源不存在、不可见或已删除 |
| 409 | 当前状态冲突，或认证尚未完成 |
| 413 | 请求体过大 |
| 429 | 请求过于频繁 |
| 500、502、503 | 服务异常或暂不可用 |

错误外形随接口不同，以各页说明为准。收到 `429` 时按 `Retry-After` 等待。
视频提交超时或结果不明确时，先核对任务与用量，避免重复生成。

## 使用边界

- 素材修改支持改名，不支持迁移到其他组。
- 图片上传不进行自动人像检测；请显式选择合适的上传模式。
- 素材组及素材 Action 的 `ProjectName` 只接受缺省或 `default`。
- 删除成功后，素材在本组接口中不可访问；存储清理由后台完成。
