# 取消或删除视频任务

~~~http
DELETE /doubao/api/v3/contents/generations/tasks/{task_id}
~~~

等价路径为 `/doubao/contents/generations/tasks/{task_id}` 和
`/doubao/v1/contents/generations/tasks/{task_id}`。请求不携带正文。

~~~bash
curl --request DELETE \
  "$BASE_URL/doubao/api/v3/contents/generations/tasks/cgt-20261030040000-abcde" \
  --header "Authorization: Bearer $API_KEY"
~~~

将创建响应中的任务 ID 完整用于删除请求。

服务先核对任务状态，再执行操作。任务必须属于当前用户，原任务使用的服务仍须可用。

| 情况 | 处理 |
| --- | --- |
| 排队任务确认取消 | 任务显示 `cancelled`，按取消结果结算 |
| 已完成任务确认删除 | 本组查询接口返回 404，列表不再显示；已完成任务删除不退款 |
| 运行中的任务 | 是否允许取消取决于生成服务；未确认成功时返回错误 |
| 状态或结果无法确认 | 保留任务及待核对状态，不能按成功处理 |

成功响应为 HTTP 200：

~~~json
{}
~~~

取消可能需要等待服务确认，客户端应允许约 90 秒的请求等待时间。
响应不明确时先查询任务；只对确认需要重试的删除操作重试，不重新创建视频。

| HTTP 状态 | 说明 |
| --- | --- |
| 400 | 请求无效或任务关联的服务不可用 |
| 404 | 任务不存在、不可见或已删除 |
| 501 | 当前任务服务不支持此操作 |
| 502、503 | 操作结果、取消确认或结算暂时无法确认 |

例如，任务关联的服务不可用时可能返回：

~~~json
{"error": {"code": "invalid_request", "message": "Task channel is unavailable"}}
~~~

错误码和消息以实际响应为准；无法确认取消或最终用量时，不应认定已退款。
